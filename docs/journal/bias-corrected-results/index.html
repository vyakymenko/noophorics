Why the gap intervals failed, tested after the run

This section rests on fields added to the record after the registered run (the † columns and Table 6; see Limits).

A percentile interval takes its location from the bootstrap, and a basic interval reflects that location about the point. In the bootstrap, the empirical frequencies play the part of the truth, so the divergence the bootstrap treats as true is the plug-in one — which is biased upward. Measured: across all 52 cells the mean of the bootstrap jackknife gap sits 0.0009–0.0027 below the plug-in estimate from the same answers, and 0.0214–0.0500 above the jackknife point (Table 6). The percentile interval is centred near the plug-in value, and the basic interval, reflected about the point, misses by about as much the other way.

Fieller's set takes only the covariance from the bootstrap, never its location. That is consistent with B2 holding while both gap intervals failed; it is not by itself a test of it. To test the location explanation, a Wald interval — centre from the point, spread from the bootstrap — was added to the record. For the jackknife it covers the true gap in 0.8875–0.9925 of trials, below 0.93 in seven cells, all at g ≤ 0.6, and below B3's 0.90 bar in one (Table 3); in the null cells it lies above zero in 0.0175–0.05 of trials (Table 5). For the movement the jackknife's Wald interval covers 0.935–0.9975 in every cell, where its registered percentile interval covers 0.88–1.00 (Table 4). These are post-registration numbers, chosen after seeing B3 fail, and are reported as that.

The zero-gap cells

With a receiver that moved away from the sender on a measure with no gap, the jackknife's percentile movement interval excluded zero on the side of moving away in 0.9425 (n = 10) and 0.995 (n = 16) of trials, and its post-registration Wald interval † in 0.8775 and 0.9925. With nothing moved, either did so in at most 0.0125 of trials (Table 5).

Compared cell for cell: with a receiver that moved, the jackknife's Fieller set is bounded in 0.03–0.0475 of trials, against V0's 0.695–0.74 and V2's 0.0025–0.01; with nothing moved, in 0.0175–0.0525, against V0's 0.0025–0.015 and V2's 0–0.0075. At a true gap of zero a bounded set is a gap reported where there is none, so the jackknife does this less often than V0 when a receiver moved, and more often than V2 in every zero-gap cell.

What this does and does not change

Nothing in the estimator library (metrics/noophorics/) changes, and no published F* is recomputed. The plan said a proposal would follow if B2 and B3 held. B3 did not, and Problem 12 stays as open as it was.

On this generator, a Fieller set for F* built from jackknife-corrected divergences held its coverage across the grid at no cost in width, and still widened without bound as the gap closed. The plug-in sets did not hold it. Neither registered interval for the gap worked, and the jackknife's gap estimate still sits above a gap of zero. A Wald construction, chosen after seeing that, covered the movement everywhere and the gap in all but seven cells.

A jackknife-Fieller report with Wald intervals for the movement and the gap is therefore an untested candidate. It would take a new registration, on a different generator of distributions, to test it — not this one, where the Wald construction was chosen after its results were seen. Whether to run that is the owner's decision.

Choices fixed in the code before the registered run

The docstring records two: the ratio's bias is the uncapped M/G over trials with G > 0.02, as for the plug-in variants; and the jackknife leaves one answer out using the library's definition of the divergence for unequal sample sizes. A smoke run of four cells at 20 trials each was executed for timing before the code was committed.

Limits

The plan's limits, all of which stand: the previous plan's — synthetic agents, three options, independent draws, one generator, a fixed frame; corrections derived for entropy are applied to a difference of entropies, and their errors need not cancel; and coverage bought with width is reported with the width, which Table 2 does.

  • The registered Miller–Madow form is not first-order bias-corrected for this divergence. It applies N = 2n to the pooled answers, but those are n answers from each party, not 2n draws from their mixture. A same-model review found by exact enumeration that this leaves a first-order bias of about Σ(p − q)²/(16 n m ln 2) bits whenever the parties differ. Its results are reported as registered; they are not evidence against Miller–Madow correction done for a stratified sample.
  • 400 trials per cell; a coverage of 0.95 has a Monte Carlo standard error of about 0.011.
  • Fields added after the registered run: the Wald intervals and the bootstrap's location (the † columns and Table 6), and a total of mismatching fields beside the reproduction check. The full run was repeated after each addition, and every registered field came out byte-for-byte identical.
